# 2026-10-21

## Resize cursors and up to three menu bar readings (contributor branch)

- Built on `feat/resize-cursors-and-menubar-trio` of a contributor's fork to show the
  owner; not approved. The decision doc's section "Proposal: resize cursors and up to
  three menu bar readings" holds what was built and why.
- Menu bar: `menuBarShows` is a list of one to three readings; a single string still
  reads. The "Menu bar shows" menu checks each pick on or off.
- Resize cursors: a 9 pt band inside the panel, 20 pt squares at the corners, and a
  6 pt ring outside it show the system's frame resize cursor; a press there resizes.
  A "Resize" switch (`resizeEdges`, on by default) turns it off, and with it off the
  window resizes from its border as before.
- What it took, found by logging the cursor during drags on the contributor's Mac:
  the system's own border resize took presses in the band and showed the arrow for the
  whole drag, which ftop could not replace, so with the switch on the panel resizes only
  through its own band and ring. A background app's cursor needs the window server
  property "SetsCursorInBackground" (private, in `Sources/CFtopSys`). Clear windows over
  the screens during a drag keep other apps' cursors (a text field's I-beam) out.
- Checked: `scripts/check.sh` run with Xcode's toolchain; reference images, including
  the menu bar with two and three readings and the control block with the new switch;
  the real panel on the contributor's Mac (two 5K displays): hover at edges and corners
  from inside and outside, fast drags, drags across text fields, three menu bar
  readings. Memory at launch 23 MB; the clear windows measured about 2.4 MB for both
  screens.
- Not checked: `scripts/perf.sh`; a single display; a full-screen space with the panel
  pinned; Reduce Motion; the switch turned off and on again on the real panel.
- Found on the way: with the Command Line Tools alone, a second `swift test` cannot
  find the Swift Testing macro plugin and fails in `CFtopSysTests`; with Xcode selected
  (or `DEVELOPER_DIR` set) it passes.
- A settings file that names several menu bar readings is not readable by 0.2.6 and
  earlier, which then use their defaults.
