# Progress 2026-10-09

## Rules for issues and pull requests

- The owner asked for a threshold after an advertisement arrived as issue 20 and a pull
  request (19) added an unofficial Homebrew tap to the README. Issue 20 was closed and
  locked as spam; pull requests 19 and 10 were closed with reasons.
- Pull requests are limited to collaborators in the repository settings. Issues go
  through two forms (a problem, which needs the output of `ftop doctor`; a suggestion)
  and blank issues are off. CONTRIBUTING.md states what is closed without a reply;
  AGENTS.md tells agents how to apply it.
- Limit: a form binds the web page only. An account posting through the API can still
  open a blank issue, so advertisements are handled after the fact.
- Not done: blocking the account behind issue 20 (the token lacks the `user` scope)
  and deleting the issue; both are left to the owner.
