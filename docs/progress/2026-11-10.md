# 2026-11-10

## Homebrew cask merged

- Homebrew/homebrew-cask pull request 300447
  (https://github.com/Homebrew/homebrew-cask/pull/300447) was approved and merged by
  bevanjkay on 2026-11-09 at 22:55 UTC as `ftop 0.2.10 (new cask)`.
- The review asked for three changes, all taken: `auto_updates true`, `desc "System
  monitor tool"`, and the setuid helper `/usr/local/libexec/ftop` moved from
  `uninstall delete` to `zap delete`. The helper is installed by `sudo ftop grant`, not
  by the cask, so removing it on every `brew upgrade` would silently revoke the grant.
  The owner answered the review personally, as the PR's AI disclosure promised.
- After the merge: formulae.brew.sh lists the cask at 0.2.10 with `"autobump": true`, so
  Homebrew's bot raises the version after each release; no manual bump is planned.
  `brew info --cask ftop` on this Mac resolves it from the official tap.
- Both READMEs now list `brew install --cask ftop` first under Install.
- Not checked: `brew install --cask ftop` from the official tap on this Mac; the first
  autobump after a release.
- Cleanup: the local copy `design/promo/homebrew-cask-ftop.rb` (identical to the merged
  cask) went to the Trash, since homebrew-cask now holds the cask. The local
  homebrew-cask tap is back on `main`, and the `ftop` branch is deleted there and on the
  owner's fork.
